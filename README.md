## 📋 Описание
SPARTA - мощный ESP скрипт для Murder Mystery V с поддержкой отображения Murder, Sheriff и Innocent.

## 🎮 Возможности
- ✅ ESP для всех ролей (Murder, Sheriff, Innocent)
- 🎨 Настраиваемые цвета для каждой роли
- 📝 Изменяемые текстовые метки
- 📏 Настройка дистанции отрисовки
- 🔤 Настройка размера шрифта
- 💾 Сохранение/загрузка конфигурации
- 🖥️ Удобный GUI интерфейс (F8)
- 🟢/🔴 Индикация состояния ESP
